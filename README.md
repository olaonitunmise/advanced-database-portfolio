# Advanced Database Systems Portfolio (MIT 8103)
An assignment designed to show an understanding of advanced database design, MIT

## Selected case study
**CityLight Public Library**

1. **Nature of the system:** It's a library management system that tracks the catalogue, members, borrowing and fines.
2. **Users:** Librarians (manage catalogue, process loans and returns), members (search and borrow), administrators (reports).
3. **Major data:** books and copies, authors, categories, members, loans, returns, fines, staff.
4. **Key operations:** It includes operations search catalogue, borrow a book, return a book, calculate overdue fines, report on popular and overdue titles. 


## Repository structure
1. `portfolio-1-database-design/`: ER diagram, schema, keys, constraints, normalisation
2. `portfolio-2-query-optimisation/`: SQL queries, execution plans, indexing, performance analysis
3. `portfolio-3-transactions-concurrency/`: commit, rollback, isolation, concurrency control
4. `portfolio-4-nosql/`: MongoDB model and implementation
5. `portfolio-5-distributed-cloud/`: replication, sharding, availability, cloud deployment
