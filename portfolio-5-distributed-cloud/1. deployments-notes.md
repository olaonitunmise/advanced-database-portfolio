## How I accessed the cluster
I worked through the Atlas web interface (Data Explorer) in the browser and did not connect from a local tool. No credentials or connection strings are stored in this repository.

## Free-tier limits that shaped this portfolio
Source: https://www.mongodb.com/docs/atlas/reference/free-shared-limitations/

- The number of nodes is fixed at 3 on a Free cluster.
- A Free cluster cannot be a sharded cluster, so sharding is covered as a design discussion only.
- Primary failover tests and regional outage simulation are not available on Free clusters, so I did not test failover.
- Backups can be enabled, but are limited (a daily snapshot, with a small number kept).
- Idle Free clusters may be deactivated, so I checked that the cluster was running before taking screenshots.

## Security observations
- The one database user has the `atlasAdmin` role on all resources, which is broader than this project needs. In a real deployment I would create a user restricted to the `citylight_library` database with read and write access only.
- Credentials are kept out of the repository. Screenshots were cropped so they do not show my account details, and the username was captured in some screenshots.
